# Animator Portfolio Website

Профессиональный веб-сайт портфолио для аниматора, разработанный с использованием современных технологий.

## 🎨 Особенности

- **Современный дизайн**: Визуально привлекательный интерфейс с градиентами и плавными анимациями
- **Полностью адаптивный**: Оптимизирован для всех устройств (мобильные, планшеты, десктопы)
- **Интерактивные анимации**: Использование Framer Motion для плавных переходов и эффектов
- **SEO-оптимизирован**: Server-Side Rendering с Next.js 14
- **Тёмная тема**: Поддержка светлой и тёмной темы
- **Блог**: Встроенная система блога для публикации статей
- **Оптимизация изображений**: Автоматическая оптимизация с помощью Next.js Image

## 📋 Разделы сайта

1. **Главная страница** - Впечатляющий hero-раздел с анимированным фоном
2. **О себе** - Информация об аниматоре и статистика достижений
3. **Портфолио** - Галерея работ с фильтрацией по категориям
4. **Опыт** - Timeline профессионального опыта
5. **Навыки** - Визуализация технических навыков с прогресс-барами
6. **Отзывы** - Карусель отзывов клиентов
7. **Блог** - Статьи и советы по анимации
8. **Контакты** - Форма обратной связи и контактная информация

## 🛠 Технологии

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: System fonts для оптимальной производительности

## 🚀 Установка и запуск

### Требования

- Node.js 18+
- npm или yarn

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd brabus
```

2. Установите зависимости:
```bash
npm install
# или
yarn install
```

3. Запустите dev-сервер:
```bash
npm run dev
# или
yarn dev
```

4. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## 🎯 Кастомизация

### Изменение контента

1. **Персональная информация**: Отредактируйте текст в компонентах `Hero.tsx`, `About.tsx`
2. **Портфолио**: Добавьте свои проекты в массив `projects` в `Portfolio.tsx`
3. **Опыт**: Обновите массив `experiences` в `Experience.tsx`
4. **Навыки**: Измените массив `skillCategories` в `Skills.tsx`
5. **Отзывы**: Добавьте отзывы в массив `testimonials` в `Testimonials.tsx`
6. **Блог**: Создайте новые посты в `data/blogPosts.ts`

### Изменение стилей

- Основные цвета настраиваются в `tailwind.config.ts`
- Глобальные стили находятся в `app/globals.css`
- Градиенты используют комбинацию `purple-600` и `pink-600`

### Изображения

Замените placeholder изображения на свои:
- Обновите URLs изображений в компонентах
- Добавьте домены изображений в `next.config.js` если используете внешние источники
